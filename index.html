What is AlgoVision?

AlgoVision is an interactive playground for seeing algorithms think. Instead of reading code on a page, you watch every comparison, swap and grid expansion happen bar by bar and cell by cell — with live counters, plain-English explainers, and experiments you can repeat as many times as you like. No install, no sign-up: everything runs right here in your browser.

1 · Sorting

Choose Bubble or Merge sort, set the array size, animation speed and input shape (random, nearly sorted, reversed, few unique), then press Run. Orange marks the pair being compared, red marks a write, green marks values confirmed in their final place.

2 · Pathfinding

Drag on the grid to draw walls (or hit Random maze), place the start and target wherever you like, then Run BFS. Watch the frontier flood outward like water and the shortest path trace its way home.

3 · Compare

Race bubble vs merge on identical arrays over several trials. It counts every comparison and array write and measures real time, so you can see quadratic vs. O(n log n) growth with your own eyes — double the size and watch the ratio climb.

Experiments worth trying

  • Run Bubble Sort on a nearly sorted input — the early-exit pass finishes almost instantly.
  • Run it again reversed — maximum comparisons, O(n²) in action.
  • In Pathfinding, wall off the target completely and watch BFS report there is no path.
  • In Compare, halve the sizes, run again, and see how each column scales.

What is breadth-first search doing?

Breadth-first search (BFS) explores the grid in “rings” around the start: first every cell 1 step away, then every cell 2 steps away, and so on. Because it always expands in this order, the first time it reaches the target it must have found a fewest-steps route — that is why BFS gives the shortest path on an unweighted grid.

Watch the frontier: it spreads like water from a tap. Cells are coloured as they join the queue (frontier) and darken once they are expanded. When the target is reached, the algorithm walks the recorded parent links backwards to reveal the path.

The comparison runs both sorting algorithms on the same random arrays, counts every elementary step, and measures real elapsed time. Results are averaged across trials. Try growing the size 2× and watch how each column scales.
